# LanRemoteDesk

轻量级局域网远程桌面工具，纯 Python 实现（Tkinter + ctypes），无需安装，支持远程屏幕查看、键鼠控制、双向剪贴板同步与双向文件传输。

## 功能特性

- **远程桌面**：实时屏幕查看（JPEG 帧传输），支持多显示器（含负坐标副屏）
- **键鼠控制**：控制端鼠标点击、拖动、键盘输入转发到被控端
- **双向剪贴板**：文本剪贴板跨机同步，双向自动感知
- **双向文件传输**：任意方向传输文件，含进度与取消
- **单文件交付**：可用 PyInstaller 打包为单个 exe，免 Python 环境运行

## 安全机制

- **认证**：HMAC-SHA256 挑战应答握手，密码不经过网络明文传输；可随机生成高强度密码
- **加密**：认证通过后所有业务帧使用 AES-256-GCM 加密，会话密钥由密码 + 随机盐经 HKDF-SHA256 派生
- **传输**：自定义帧协议（类型 + 长度 + 加密体），发送路径加锁串行化，杜绝并发帧交错损坏

## 快速开始

### 依赖

- Windows（键鼠注入与剪贴板使用 Win32 API）
- Python 3.8+（开发环境为 3.12）
- 第三方库：`pycryptodome`、`Pillow`

```bash
pip install pycryptodome Pillow
```

### 运行

```bash
cd src
python main.py
```

启动后为三选一菜单：

| 模式 | 说明 | 命令行直达 |
|------|------|-----------|
| 主菜单 | 默认，双按钮选择 | `python main.py` |
| 被控端 | 生成/设置密码并监听端口（默认 5900） | `python main.py -s [-P 密码] [-p 端口]` |
| 控制端 | 输入 IP、端口、密码连接 | `python main.py -c` |

### 运行自测

```bash
cd tests
python selftest.py
```

覆盖协议编解码、加解密、认证握手、坐标映射、抓屏韧性、文件收发压测等 19 项。

## 目录结构

```
LanRemoteDesk/
├── src/
│   ├── main.py         # 入口与命令行解析
│   ├── common.py       # 协议帧、AES-256-GCM 加密、认证握手
│   ├── desk_server.py   # 被控端：抓屏、输入注入、文件接收
│   ├── desk_client.py  # 控制端：收屏、键鼠事件发送
│   ├── native.py       # Win32 键鼠注入 / 剪贴板接口（ctypes）
│   ├── ui_server.py    # 被控端界面
│   ├── ui_client.py    # 控制端界面（等比缩放、坐标映射）
│   └── ui_main.py      # 主菜单
└── tests/
    └── selftest.py     # 自测套件
```

## 已知限制

- 被控端需保持桌面解锁（锁屏 / RDP 会话断开会导致黑屏，恢复后自动续帧）
- 首次以单文件 exe 启动有 5–10 秒解压延迟（源码运行无此问题）
- 键盘转发不支持输入法逐字输入
- 远端 UAC 弹窗、锁屏界面需本人在被控端配合操作
- 需在防火墙放行被控端监听端口（默认 5900）
